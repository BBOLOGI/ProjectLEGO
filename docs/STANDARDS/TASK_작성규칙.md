# TASK 작성규칙

## TASK 번호 규칙

TASK 번호는 `TASK-0001`과 같이 `TASK-`와 네 자리 일련번호를 사용한다.

## 필수 구성

TASK에는 다음 항목을 명확히 작성한다.

- 작업 목적
- 작업 범위
- 제외 범위
- 선행 조건
- 작업 위치
- 요구 결과물
- 필수 검증
- 선택 검증
- 완료 조건
- 중단 조건
- 완료 보고 형식

필수 검증과 선택 검증을 구분하고, 완료 조건은 실제로 확인 가능한 형태로 작성한다.
