# Commit 규칙

## 변경 단위

Commit은 하나의 명확한 변경 단위로 작성한다.

## 기본 형식

`<접두어>: <변경 내용을 설명하는 제목>`

## 권장 접두어

- `feat`: 기능 추가
- `fix`: 오류 수정
- `docs`: 문서 변경
- `test`: 시험 추가 또는 수정
- `refactor`: 동작 변경 없는 구조 개선
- `chore`: 유지관리 및 기반 작업

## 제목 작성 규칙

제목은 간결하고 구체적으로 작성하며 무엇이 변경되었는지 드러나게 한다.

## 본문 작성이 필요한 경우

변경 이유, 영향, 제약 또는 검증 방법을 제목만으로 설명하기 어려울 때 본문을 작성한다.

## 금지되는 모호한 메시지 예시

- `update`
- `fix`
- `changes`
- `작업함`
