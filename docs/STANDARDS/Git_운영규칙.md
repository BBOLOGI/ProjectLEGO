# Git 운영규칙

## 담당자

GitHub 저장소 작업 담당자는 C기사다.

## 기준 브랜치

기준 브랜치는 `main`이다.

## 작업 전 Pull 또는 Fetch 원칙

작업 전에 `origin`을 Fetch하고 로컬과 원격의 차이 및 작업 트리를 확인한다.

## 기존 파일 보호 원칙

기존 파일은 먼저 읽고 비교하며 임의로 삭제하거나 덮어쓰지 않는다.

## Commit 전 확인 사항

변경 목록, 예상하지 않은 삭제, 공백 오류, Build 및 Test 결과를 확인한다.

## Push 전 확인 사항

현재 브랜치, Commit 내용, 원격 차이와 Push 대상을 확인한다. 강제 Push는 하지 않는다.

## 충돌 발생 시 처리

충돌을 임의로 해소하지 않고 원인과 영향 범위를 보고한 뒤 승인된 방식으로 처리한다.

## 로컬과 원격 SHA 확인

Push 후 로컬 `HEAD`와 `origin/main` SHA가 일치하는지 확인한다.

## GitHub Actions

GitHub Actions는 후속 검증이며 필수 완료 조건으로 강제하지 않는다. 확인 불가나 일시 장애는 별도로 보고한다.
