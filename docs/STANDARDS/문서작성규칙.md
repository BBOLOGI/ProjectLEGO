# 문서작성규칙

## 기본 형식

공식 문서는 Markdown으로 작성한다.

## 문서 메타데이터

문서 성격에 따라 다음 정보를 명확히 표시한다.

- 문서 제목
- 문서 번호
- 상태
- 작성자 역할
- 승인자
- 작성일과 수정일
- 관련 TASK·SPEC 링크

## 파일명 규칙

내용을 식별할 수 있는 일관된 파일명을 사용하고, 해당 문서 체계의 기존 명명 규칙을 따른다.

## 기존 문서 수정 원칙

기존 내용을 먼저 확인하고 필요한 부분만 수정한다. 삭제, 대규모 재작성 또는 의미 변경은 승인 후 수행한다.
