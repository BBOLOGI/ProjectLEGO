# TASK-0003 LEGO Search UI 수동 시험

## 시험 환경

- Windows 10 이상
- .NET 8 Desktop Runtime
- 실행 파일: `src/ProjectLEGO.Desktop/bin/Release/net8.0-windows/ProjectLEGO.Desktop.exe`
- 샘플 데이터는 기능 시험용이며 실제 설계 표준이 아니다.

## 시험 항목

| 항목 | 확인 방법 | 기대 결과 |
|---|---|---|
| 앱 실행 | 실행 파일 시작 | 전체 활성 LEGO 8개 표시 |
| Enter 검색 | `집수정` 입력 후 Enter | 집수정 3개 표시 |
| Template 필터 | 집수정 선택 | 가로·세로·높이·재질·형태 필터 자동 생성 |
| Number 필터 | 가로 최소 1000, 최대 1100 | 해당 범위 Record만 표시 |
| Boolean 필터 | 옹벽 선택 후 내진 고려=예 | 내진 Record만 표시 |
| Select 필터 | 집수정 형태=원형 | 원형 Record만 표시 |
| 0건 메시지 | 일치하지 않는 검색어 입력 | 안내 메시지 표시 |
| 선택 강조 | 결과 행 선택 | 선택 행과 하단 이름·LegoId 표시 |
| 삽입 요청 | 선택 후 버튼 또는 더블클릭 | 요청 이벤트와 후속 연결 안내 표시 |
| 미선택 상태 | 검색 직후 확인 | 삽입 요청 버튼 비활성화 |
| 초기화 | 검색·필터 후 초기화 | 검색어·종류·필터·정렬·선택 초기화 |
| 잘못된 AssetPath | 샘플 Record 선택 후 폴더 열기 | 경고 표시, 앱은 계속 실행 |
| 고해상도 배율 | Windows 배율 변경 후 실행 | 컨트롤 내용 식별 가능 |
| 창 크기 변경 | 창 확대·축소 | 좌측 필터와 결과 영역 유지 |

## 실행 기록

자동화 가능한 검색·필터·선택 요청 로직은 xUnit으로 검증한다. UI 렌더링과
상호작용은 실제 앱 실행 화면에서 확인하며, 실제 CAD 삽입은 수행하지 않는다.

### 2026-07-26 실행 결과

- 앱 실행: 성공
- 초기 활성 LEGO: 8개 표시
- 데이터 오류 상태: Template 0건, LEGO 0건

- 결과 정보: Template, Category, 주요 규격, Tags 표시 확인
- 미선택 상태: 폴더 열기·삽입 요청 버튼 비활성화 확인

- 동적 필터·정렬·삽입 요청 모델: xUnit 자동 시험 통과
