# TASK-0004 Search UI v2.0 시험

## 자동 시험

- 공백·대소문자·`×/x/X`·`=` 정규화
- 이름·규격·설명·태그 부분 검색
- 규격1~4 단계별 옵션 조회
- 상위 규격에 따른 하위 옵션 변경
- 완전하고 유일한 규격 선택에서만 최종 Record 결정
- `ILegoRepository` 계약을 통한 SearchService 데이터 조회

## UI 수동 시험

1. 앱 실행 후 전체 LEGO 결과를 확인한다.
2. `집수`, `1000 x 1000`, `H=3.0`으로 검색한다.
3. 검색 결과를 선택하고 규격1~4가 순차 활성화되는지 확인한다.
4. 상위 규격을 변경하고 하위 선택이 초기화되는지 확인한다.
5. 최종 Record 결정 전 열기·삽입 버튼이 비활성인지 확인한다.
6. 최종 Record 결정 후 파일명·경로 Preview와 버튼 활성화를 확인한다.
7. 열기·삽입 버튼이 Mock 안내를 표시하고 실제 CAD 작업을 하지 않는지 확인한다.
8. 창 크기와 Windows 배율 변경 시 레이아웃을 확인한다.
